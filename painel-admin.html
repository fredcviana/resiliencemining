SQL — Criar tabela no Supabase

Cole este SQL no SQL Editor do seu projeto Supabase (supabase.com → projeto → SQL Editor → New query):

-- Execute no SQL Editor do Supabase -- Se a tabela já existe, rode apenas o bloco ALTER TABLE abaixo CREATE TABLE IF NOT EXISTS survey_responses ( id bigserial PRIMARY KEY, response_id text NOT NULL, lang text, country text, respondent_profile text, org_size text, answers jsonb DEFAULT \'{}\', completed boolean DEFAULT false, submitted_at timestamptz, updated_at timestamptz DEFAULT now(), created_at timestamptz DEFAULT now(), -- UNIQUE obrigatório para o upsert funcionar CONSTRAINT survey_responses_response_id_key UNIQUE (response_id) ); -- Índices para performance CREATE INDEX IF NOT EXISTS idx_sr_country ON survey_responses(country); CREATE INDEX IF NOT EXISTS idx_sr_completed ON survey_responses(completed); CREATE INDEX IF NOT EXISTS idx_sr_lang ON survey_responses(lang); -- Se a tabela já existia sem UNIQUE, rode isto: -- ALTER TABLE survey_responses -- ADD CONSTRAINT survey_responses_response_id_key UNIQUE (response_id); -- Row Level Security ALTER TABLE survey_responses ENABLE ROW LEVEL SECURITY; DROP POLICY IF EXISTS "allow_insert_update" ON survey_responses; CREATE POLICY "allow_insert_update" ON survey_responses FOR ALL USING (true) WITH CHECK (true);

Onde encontrar as credenciais

1. Acesse supabase.com → seu projeto
2. Menu lateral → Project Settings → API
3. Copie a Project URL e a chave anon public
4. Cole acima e clique em Salvar
5. Execute o SQL acima para criar a tabela
6. Cole as mesmas credenciais no questionario.html (linhas 2–3 do script)
